> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 8 + pytest-cov (API); vitest 2 (apps); Playwright 1.65 (e2e/visual) |
| **Config file** | `apps/api/pyproject.toml [tool.pytest.ini_options]`, `playwright.config.ts`; falta `supabase/config.toml` (Wave 0) |
| **Quick run command** | `cd apps/api && uv run pytest -q -x` · `pnpm -r lint && pnpm -r typecheck` |
| **Full suite command** | `supabase db reset && cd apps/api && uv run ruff check && uv run ruff format --check && uv run mypy app && uv run pytest -q --cov=app --cov-fail-under=70 && cd ../.. && pnpm lint && pnpm typecheck && pnpm test && pnpm build` |
| **Estimated runtime** | ~180 seconds (local, con Supabase ya levantado) |

---

## Sampling Rate

- **After every task commit:** `uv run pytest -q -x` (si toca la API) o `pnpm --filter <app> lint typecheck build`
- **After every plan wave:** suite completa local (`supabase db reset` + todo)
- **Before `/gsd:verify-work`:** CI verde en el PR a `dev`, despliegue a dev, `e2e-dev` verde, evidencia humana de prod en `verificacion.md`
- **Max feedback latency:** 180 seconds
